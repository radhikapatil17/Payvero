# Payvero Frontend

**Payvero — Distributed Digital Payment & Financial Ledger Platform (Web Interface)**

React + TypeScript + Vite web application for the Payvero financial platform.

## Features
- Real-time balance and transaction history visualization
- Idempotency-protected payment execution form
- Period-closed statement explorer
- Admin dashboard for fraud review and audit log inspection

## Available Scripts
- `npm run dev` — Start Vite development server
- `npm run build` — Build production bundle (`tsc -b && vite build`)
- `npm run test` — Run test suite with Vitest
- `npm run lint` — Lint code with Oxlint
